# LATENTFLOW
# 🎬 AI Movie Recommendation System

A modern and aesthetic web-based Movie Recommendation System frontend designed to simulate an AI-powered recommendation engine.

## 🚀 Project Overview
This project demonstrates the frontend workflow of a Movie Recommendation System that integrates Machine Learning techniques such as:

- Content-Based Filtering
- Collaborative Filtering
- Cosine Similarity
- User Preference Modeling

The current version showcases a responsive and visually engaging UI prototype built to simulate real-time recommendation output.

## ✨ Features
- Modern dark-themed UI (Netflix-inspired design)
- Search-based movie input
- Genre selection filter
- Dynamic recommendation display
- Responsive movie cards with ratings and descriptions
- Smooth hover animations
- Clean and intuitive layout

## 🛠 Tech Stack
- HTML5
- Tailwind CSS
- JavaScript
- Machine Learning
